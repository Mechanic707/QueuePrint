## 序印 QueuePrint v0.1.4

打印队列改为文件级进度，多个文件合并为一个 Windows 作业时，也能看到每个文件的处理情况。

### 新增与改进

- 主进度显示已处理文件数／文件总数，另显示已确认提交的文件数。
- 当前文件展示名称、目录、内容页数和第几份；多份、多套同时显示处理份次。
- 逐文件列出待处理、处理中、已处理待提交、已提交和待核对状态。
- Windows 任务编号和技术名称放入默认折叠的详情中，实时更新保留展开和滚动位置。
- 按每份文件跟踪进度，重复页、附加空白和重复回执不会造成重复计数。

文件处理完成只表示绘制完成；所属 Windows 作业确认提交后，才计入“已确认提交”。实际出纸仍以打印机为准。打印分组、文件顺序、暂停和停止后续作业的行为保持原样。

### 下载

关闭旧版后运行 `QueuePrint-0.1.4-win-x64.exe`。`SHA256SUMS.txt` 提供发布文件的校验值。

### 验证

59 项 Node 测试、原生只读计划与渲染检查，以及模拟进度的实际 Electron 界面检查。检查不向真实打印机提交作业。
