## 序印 QueuePrint v0.1.7

修复打印内容缩在页面左下方、部分内容被裁切的问题。

### 修复内容

- 修正横向打印的可打印区域计算。部分驱动已经返回横向设备尺寸，旧路径再次换向，导致 PDF 和图片按错误区域缩放、居中。
- 直接从当前打印设备上下文读取纸张尺寸、可打印范围、硬件偏移及 DPI；实际打印和纸张效果预览使用同一套几何数据。
- 新增 Microsoft Print to PDF 输出回归，通过真实 `PrintDocument.Print()` 路径生成自建 PDF/PNG 的打印结果，检查页面尺寸、横纵方向及四角内容完整性。

### 下载与验证

关闭旧版后运行 `QueuePrint-0.1.7-win-x64.exe`。校验值见 `SHA256SUMS.txt`。

80 项 Node 测试继续覆盖目录、份数、提交状态与预览逻辑。打印输出回归仅使用系统虚拟 PDF 打印机，输出限定在 `.qa/`；CI 缺少该驱动时明确跳过，不自动安装或改用其他打印机。本次未向实体设备提交作业。
