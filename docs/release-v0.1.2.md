## 序印 QueuePrint v0.1.2

修复 v0.1.1 便携版重复启动后提示“本地打印组件尚未构建”、无法提交打印的问题。

### 修复内容

- 每次启动使用独立临时解压目录，第二个启动进程退出时不会删掉原窗口所需的打印组件。
- 打包前检查本地打印助手、PDFium 及自包含 .NET 运行库，缺失时停止打包。
- 验证最终便携 EXE 重复启动后的原生组件访问，而非只检查目录版。
- 发行版组件缺失时提示重新打开或下载完整程序，无需安装开发工具或执行构建命令。

### 升级

关闭所有旧版序印窗口，再运行 `QueuePrint-0.1.2-win-x64.exe`。保留单文件多份、文件夹拖放、目录顺序、预览及打印属性等功能。

`SHA256SUMS.txt` 提供发布文件校验值。

### 验证

通过自动测试、完整原生文件比对，以及最终便携程序重复启动后的只读打印机枚举、文件检查与 PDF 渲染回归。本次检查没有向真实打印机提交作业。
