## 序印 QueuePrint v0.1.3

修复便携版组件丢失及 Windows 路径大小写兼容问题。

### 修复内容

- 保留 v0.1.2 的独立解压目录修复，重复打开程序时不会清理原窗口仍需使用的打印组件。
- 修复临时目录盘符或路径大小写变化时，界面请求被误拦截的问题。
- 打包前验证本地打印助手与自包含运行库；发行版组件缺失时给出适合用户的恢复提示。
- 移除窗口标题中硬编码的旧版本号。

### 升级

关闭所有旧版序印窗口，再运行 `QueuePrint-0.1.3-win-x64.exe`。无需运行 `npm run native:build` 或安装开发工具。

`SHA256SUMS.txt` 提供发布文件校验值。

### 验证

51 项自动测试覆盖打印计划、提交状态、组件完整性及路径校验。最终便携 EXE 在常规和小写临时目录下验证重复启动、打印机枚举、文件检查和 PDF 渲染；检查不向真实打印机提交作业。
