## 序印 QueuePrint v0.1.5

修复预览缩放和文件切换，预览中即可连续查看整批材料。

### 新增与修复

- 顶部文件选择器按清单顺序分组，支持上一文件／下一文件；点击其他文件夹也可打开其中的文件。
- 可输入 10%–400% 缩放比例，使用加减按钮或 Ctrl＋滚轮缩放，放大后按住左键拖拽查看。
- 提供适合宽度、适合整页、100% 和页码跳转。
- 修复快速 A→B→A 切换时误用已销毁 PDF 缓存，以及旧渲染结果覆盖当前文件的问题。
- 重新导入已更新文件后刷新缓存；图片缩放复用当前内容，PDF 渲染限制像素预算。

这些操作只改变预览，不修改文件勾选、份数或打印属性。

### 下载与验证

关闭旧版后运行 `QueuePrint-0.1.5-win-x64.exe`。`SHA256SUMS.txt` 提供发布文件校验值。

67 项 Node 测试与实际 Electron 预览检查，覆盖自由缩放、快速切换、PDF/图片互切、缓存更新和错误恢复；检查不提交实际打印作业。
