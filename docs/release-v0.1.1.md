## 序印 QueuePrint v0.1.1

Windows 本地批量打印工具，支持 PDF / JPG / PNG 混合导入、目录分组和自然排序。

### 本版功能

- 在清单中直接编辑单文件份数；支持与整批套数相乘，并在提交前核对最终顺序。
- 从资源管理器拖入一个或多个文件夹，也可混合拖入文件；递归保留子目录分组。
- 重复拖入去重，并保留已有份数及勾选状态。
- 支持打印机选择、属性继承、驱动高级属性、PDF/图片预览与双面文件边界处理。

### 下载与使用

下载 `QueuePrint-0.1.1-win-x64.exe`，关闭旧版本后运行。免安装程序已包含 Electron 与本地打印助手运行时，打印机需先在 Windows 中安装驱动。

`SHA256SUMS.txt` 提供安装包 SHA-256 校验值。当前程序未做代码签名。

### 验证范围

38 项 Node 测试及实际 Electron 桌面导入、拖放、预览和份数检查已通过。默认 PDF 打印渲染为 300 DPI；实际设备的出纸方向、翻边与纸盒等驱动选项请先用少量材料核对。
